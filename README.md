# Grimhold — статус

Страница-презентация проекта: о чём игра, как она выглядит и на чём разработка
стоит сейчас. Сделана одним файлом без сборки — открывается как есть.

- `index.html` — вся страница
- `arts/` — концепт-арты, пережатые в webp (все восемь весят меньше четырёхсот килобайт)

## Страница

**https://wprotvbanke.github.io/Grimhold-status/**

GitHub Pages уже включён (ветка `main`, корень репозитория) — настраивать ничего
не нужно, ссылку можно давать как есть. Локально страница тоже открывается:
достаточно открыть `index.html` в браузере.

## Как обновлять

Править `index.html` и коммитить в `main` — Pages пересоберётся сам за минуту.

Новые арты класть в `arts/` **уже пережатыми**: исходники на несколько мегабайт
грузятся у друзей по десять секунд. Эти восемь сжаты в webp по длинной стороне
и вместе весят меньше четырёхсот килобайт.
