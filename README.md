# Grimhold — статус

Страница-презентация проекта: о чём игра, как она выглядит и на чём разработка
стоит сейчас. Сделана одним файлом без сборки — открывается как есть.

- `index.html` — вся страница
- `arts/` — концепт-арты, пережатые в webp (все восемь весят меньше четырёхсот килобайт)

## Как открыть

Локально — просто открыть `index.html` в браузере.

В сети — через **GitHub Pages**: Settings → Pages → Source: `Deploy from a branch`,
ветка `main`, папка `/ (root)`. Через минуту страница будет доступна по адресу
`https://wprotvbanke.github.io/Grimhold-status/`.

## Как обновлять

Править `index.html` и коммитить. Новые арты класть в `arts/` уже пережатыми —
исходники на несколько мегабайт грузятся у друзей по десять секунд.
